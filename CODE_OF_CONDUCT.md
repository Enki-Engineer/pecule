# Code of conduct

[Lire en français](CODE_OF_CONDUCT.fr.md)

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we treat each other with consideration, we criticise ideas and code, never people, and no harassment is
tolerated. Unacceptable behaviour is reported privately to the maintainers through GitHub's reporting (the
maintainer's profile → "Report"), or by private message. The maintainers may remove a comment, close a discussion or
exclude someone from the project.
