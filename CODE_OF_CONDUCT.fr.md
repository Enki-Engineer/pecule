# Code de conduite

[Read in English](CODE_OF_CONDUCT.md)

Ce projet applique le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En bref : on se parle avec égards, on critique les idées et le code, jamais les personnes, et aucun harcèlement n'est
toléré. Un comportement inacceptable se signale en privé aux mainteneurs par le signalement de GitHub (profil du
mainteneur → « Report »), ou par un message privé. Les mainteneurs peuvent retirer un commentaire, fermer une
discussion ou exclure une personne du projet.
